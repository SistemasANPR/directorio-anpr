# Documentación ANPR México

Esta carpeta contiene toda la documentación técnica y de usuario para la plataforma ANPR México.

## Índice de Documentación

### 📖 [README Principal](../README.md)
Descripción general del proyecto, instalación, configuración y comandos principales.

### 🏗️ [Guía de Arquitectura](./architecture.md)
Documentación completa de la arquitectura del sistema:
- Patrones de diseño implementados

- Flujo de datos y estado
- Decisiones técnicas importantes
- Estrategias de escalabilidad

### 👥 [Manual de Usuario](./user-manual.md)
Guía completa para todos los tipos de usuarios:
- **Visitantes**: Navegación y búsqueda en el directorio

## Cómo Usar Esta Documentación

### Para Desarrolladores
1. Comenzar con el **README Principal** para configuración inicial
2. Revisar **Guía de Arquitectura** para entender el diseño del sistema
3. Consultar **Esquema de Base de Datos** para desarrollo de nuevas funcionalidades

### Para Usuarios Finales
- Consultar el **Manual de Usuario** según tu rol en la plataforma
- Cada sección incluye guías paso a paso con capturas y ejemplos

### Para Administradores
- **Manual de Usuario** (sección de administradores) para gestión diaria
- **Esquema de Base de Datos** para mantenimiento y monitoreo

## Mantener la Documentación Actualizada

- Actualizar documentación con cada nueva funcionalidad
- Revisar y validar ejemplos regularmente
- Solicitar feedback de usuarios para mejorar claridad
- Versionar cambios importantes en la documentación
